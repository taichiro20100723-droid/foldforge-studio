# FoldForge Studio

STLを読み込み、0.8 mmの3Dプリントパネルと15Dチュールを一体化した「平面から立体へ変形するシート」へ変換する、オフライン対応の試作ツールです。

ブラウザーで `FoldForge_Studio_Standalone.html` を開くだけで使えます。STLは外部へ送信せず、ブラウザー内で解析します。

## まず試す順番

1. **亀甲シェル（弾性モーフ）** — 実物写真の六角パネル曲面に最も近く、成功率を確認しやすい。
2. **猫マスク（弾性モーフ）** — 平面から顔・耳・口先が立ち上がる。今回の主目的に最も近い。
3. **ハイパー鞍面（弾性モーフ）** — 押す方向で凹凸が変わり、動きが分かりやすい。
4. **マンタ翼（弾性モーフ）** — 布ヒンジのしなりが見た目へ直結する。
5. **測地ドーム（厳密ネット）** — パネル寸法を保つ方式を試す基準形。
6. **フチコマ風・思考戦車（弾性モーフ）** — 最も見栄えがするが、局所固定と成形治具が必要。

## 二つの変換方式

### 弾性モーフ（推奨）

STLを最適な平面へ投影し、小さな独立パネルへ分割します。パネル間の15Dチュールが伸び、隙間が開閉することで、平面から猫の顔・甲羅・鞍面などの二重曲面へ近づきます。

- 原則1枚の連続シート
- 外周印刷枠なし
- 猫、顔、マスク、レリーフ、甲羅、翼、波面向け
- 厳密な剛体折りではなく、布の伸びを含む近似変形
- 閉じたSTLは、自動設定では投影方向の表側シェルを抽出

### 厳密ネット

三角形の辺長を変えず、面の双対グラフから展開木を探索します。重なりが残る部分は複数の島へ分け、同じ `S番号` の縁を最後に閉じます。

- 多面体の面形状を保持
- 凸形状、筒、ドーム、機械外装向け
- 紫の同じS番号を磁石、糸、薄いテープなどで閉じる
- 任意の閉じた多面体は切れ目なしの一枚へ展開できるとは限らない

## 標準設定

| 項目 | 値 |
|---|---:|
| 完成形の最長辺 | 150 mm |
| 印刷ベッド | 256 × 256 mm |
| 布固定余白 | 外周30 mm |
| パネル厚 | 0.8 mm |
| 一時停止高さ | 0.4 mm |
| 折り線すき間（布の位置） | 1.0 mm |
| 山折りのL4後退量 | 片側 +1.10 mm |
| 谷折りのL1後退量 | 片側 +0.45 mm |
| 頂点リリーフ面取り | 0.85 mm |
| セレーション | ±0.35 mm / ピッチ6 mm |
| 最小パネル間すき間（保証値） | 0.80 mm |
| 推奨積層 | 0.20 mm |

印刷STLには四角い外周枠を生成しません。パネルはベッド中央の約196 × 196 mmへ自動配置し、外側約30 mmはチュールを磁石で張る領域として空けます。

## 印刷手順

1. `*_PRINT_0p8mm.stl` をスライサーへ読み込み、倍率100%・Z厚0.8 mmを確認する。
2. 積層0.20 mm、壁2〜3本、初層を十分に密着させる。
3. 高さ0.40 mmで一時停止を設定する。
4. 停止したらノズルを退避し、15Dチュールをしわなく張る。
5. ベッド外周の印刷されない領域で、薄い磁石または耐熱テープを使って固定する。
6. ヘッドの移動経路へ磁石が入っていないことを確認する。厚い磁石はノズル衝突の危険がある。
7. 再開直後の1〜2層を15〜20 mm/s程度に落とす。
8. 冷めてから取り外し、最初は小さな角度で全ヒンジを慣らす。

パネルは4層構成です。布に接する第2層と第3層は**同一の平面形状**なので、布が下の樹脂に乗っているのに上に樹脂がない帯ができません（ここが剥離の起点になります）。山折り・谷折りのクリアランスは第1層と第4層だけに持たせています。

上面から見て、**すき間が広い折り線が山、狭い折り線が谷**です。STLをZ方向にミラーすると全ての山谷が入れ替わります。

長い折り線には逆位相のセレーションが入っています。隣り合う2枚は必ず逆位相なので内寄せ量の和は一定で、折り角は落ちないまま掴み線が方形波になり、剥離クラックが折り線に沿って直進できません。

## 成形方法

### 弾性モーフ

1. 画面の変形スライダーと `*_TARGET_SIMPLIFIED.stl` を見て、表裏を確認する。
2. 中央の最も高い部分から少しずつ押し出す。
3. 一気に最終形へせず、中央→中間→外周の順で3周ほど繰り返す。
4. 形が戻る部分だけ、小型磁石、糸、仮治具で固定する。
5. 猫耳、角、機械脚など尖った部分は最後に立てる。

### 厳密ネット

1. SVGの実線を山、破線を谷として軽く予備折りする。
2. 組立JSONの深さ順に、中心面から外側へ折る。
3. 紫の同じ `S番号` を合わせる。
4. 仮止めで全体形状を確認してから本固定する。

## 出力ファイル

- `*_PRINT_0p8mm.stl` — チュール埋め込み用の印刷本体
- `*_TARGET_SIMPLIFIED.stl` — 目標形状の簡略版
- `*_ASSEMBLY.svg` — 面番号、山谷、閉じ縁番号
- `*.fold` — FOLD 1.1形式の平面・立体データ
- `*_ASSEMBLY.json` — ヒンジ角、順序、警告、寸法
- 一括ZIP — 上記と短い印刷メモをまとめたもの

## STL入力のこつ

- 最初は20〜150面程度のローポリSTLが最も安定します。
- 高密度STLは最大パネル数へ向けて自動簡略化しますが、細い指・アンテナ・薄板は消えることがあります。
- 猫の全身より、猫マスク、頭部正面、背中の甲羅など「一方向から見える皮」を入力すると成功しやすいです。
- フチコマのような多部品形状は、胴体・脚・センサーを別STLにして変換し、最後に組み立てる方が現実的です。
- STLの単位情報は規格上入らないため、ツール側で最長辺を指定サイズへ正規化します。

## 重要な限界

「任意のSTLを、切れ目も伸びもない普通の一枚の紙へ自動変換する」問題と、本ツールのチュールヒンジ構造は同じではありません。FoldForgeは次の二つの逃げを意図的に使います。

- 弾性モーフ：布の伸びとヒンジ隙間によって曲率を作る
- 厳密ネット：展開の切れ目を、後から閉じるS番号へ変換する

そのため、これは実用的な試作生成器ですが、どのSTLでも一回で目標形へ自動スナップする完成済み逆設計ソルバーではありません。まず小型で印刷し、チュールの張力と隙間を較正してください。

## 技術的な位置づけ

- Demaine・TachiのOrigamizerは、任意の向き付け可能な多面体を折るための理論的・実用的アルゴリズムを提示しています。FoldForgeの厳密ネットは、その完全なタック分子方式ではなく、製作しやすい展開木と閉じ縁へ簡略化しています。  
  https://origami.c.u-tokyo.ac.jp/~tachi/cg/DemaineTachiOrigamizerSoCG2017.pdf
- FOLD形式は、平面の折線、山谷、面、折られた状態を保存するための公開形式です。  
  https://github.com/edemaine/fold
- 厚いパネルでは理想的なゼロ厚折りと干渉条件が変わります。FoldForgeは布ヒンジ隙間と段差クランプでこれを回避します。  
  https://scholarsarchive.byu.edu/facpub/1605/
